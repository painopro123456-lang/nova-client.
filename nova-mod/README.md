# NOVA In-Game
Fabric client mod source targeting Minecraft 26.2.

Prototype:
- Right Shift opens and closes a custom in-game NOVA menu.
- Dark translucent panel, violet accent, category sidebar and module cards.
- Module switches currently change prototype UI state only; they do not activate real gameplay modules yet.

Planned next:
- Real HUD modules and settings.
- Installed-mod management.
- Modrinth and CurseForge search and installation with compatibility/dependency checks.
- Restart-required notices for mod changes.

Build requires JDK 25 and Gradle 9.5.1. Run gradle build. Output should be in build/libs.
This is source scaffolding, not a tested release jar.
